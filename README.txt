ملتقى التعليم التفاعلي (تفاعل)

ابدئي بملف index.html الموجود مباشرةً داخل هذا المجلد.
هذا الملف يضم اللعبة كاملة: HTML وCSS وJavaScript والصور والخطوط.
لا يتطلب تحميل ملفات أخرى أو تشغيل خادم محلي.

التشغيل على الكمبيوتر:
١. فكّي ضغط الحزمة.
٢. افتحي index.html بمتصفح حديث مثل Edge أو Chrome.
٣. اضغطي «ابدأ المغامرة» أو اختاري إحدى المحطات الخمس.

رفع الملف إلى مستودع GitHub:
١. افتحي مستودع اللعبة.
٢. اختاري Add file ثم Upload files.
٣. ارفعي index.html إلى المستوى الرئيسي للمستودع.
٤. احفظي التغييرات عبر Commit changes؛ وقد يظهر Propose changes عند اختيار فرع جديد.
إذا كان المستودع فارغًا، قد يظهر رابط uploading an existing file.
رفع الملف يحفظ الكود في المستودع. إظهار اللعبة كرابط موقع يحتاج إعداد الاستضافة على الخدمة التي تختارينها.

عرض الكود والتعديل:
افتحي index.html باستخدام محرر نصوص. الصور والخطوط مخزّنة داخله كنصوص طويلة تبدأ بـ data:؛ احتفظي بها كاملة.
داخل source توجد ملفات المصدر الأصلية مفصولة لتسهيل التعديل:
index.html: الصفحة الأساسية.
style.css: الألوان والخطوط والتنسيق والاستجابة للشاشات.
engine.mjs: الأسئلة والحساب والتقييم والنجوم.
app.mjs: عرض الشاشات والأزرار والتفاعل.
assets: الصور والخطوط الأصلية.
نسخة source تستخدم وحدات JavaScript وتحتاج إلى استضافة ويب أو خادم محلي عند تشغيلها. للتشغيل بالنقر المباشر استخدمي ملف index.html الرئيسي.

الجديد في هذه النسخة:
نماذج تفاعلية للعشرات والآحاد داخل أسئلة الطرح الثمانية والمسألتين اللفظيتين.
تظهر النماذج تلقائيًا، ويمكن إخفاؤها أو إعادة تمثيل العدد.
فكّ عشرة عند الحاجة فقط، ثم انقر القطع لاستبعاد المطروح؛ انقرها مرة أخرى لإعادتها.
عدّ الباقي بنفسك؛ لا يظهر الناتج رقميًا قبل الإجابة الصحيحة.
يمكن اختيار الإجابة ذهنيًا دون استعمال النماذج. بعد الإجابة الصحيحة يظهر النموذج المكتمل.
كل حزمة مقسّمة بصريًا إلى ١٠ وحدات، والآحاد يمينًا والعشرات يسارًا.

المحتوى:
بنك العشرات؛ كنز الباقي؛ حديقة المسائل؛ بيوت الأعداد؛ عدسة التقدير.
٢٢ سؤالًا، ونشاط إعادة التجميع، بإجمالي ٢٣ نجمة فريدة.
جواز إنجاز قابل للطباعة، تلميحات ومحاولات متكررة دون خصم نجوم.
أرقام عربية، واتجاه من اليمين إلى اليسار، واسم المعلمة وشعار الملتقى.
اللعبة دون موسيقى أو أصوات.
تحديث الصفحة أو إغلاقها يبدأ رحلة جديدة؛ التقدم محفوظ أثناء الجلسة الحالية فقط.

التحقق:
نُقل منطق اللعبة من النسخة المنشورة، ثم فُحص التصدير البرمجي وتضمين الأصول.
لا يُعد الفحص البرمجي معاينة بصرية داخل متصفح فعلي.
